Backups & recovery

Export the portal records and website content in an encrypted file. This does not include uploaded photo files, website source code, or Urable records.

Encrypted backup

Downloads customer profiles, vehicles, privacy requests and site content as a file locked with a passphrase you choose. The passphrase is never sent anywhere. If you lose it, the backup cannot be opened.

Restore from backup

Restore updates matching records from the file. It never deletes anything. You see what is in the file before anything changes.
